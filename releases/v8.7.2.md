# MobHunting 8.7.2

MobHunting 8.7.2 is a patch release for player deaths caused by projectiles whose
shooter is no longer available.

## Fix

- Prevents a `NullPointerException` while processing a player death when
  `Projectile#getShooter()` returns `null`.
- Reads the projectile shooter once and preserves the existing attribution to a
  player or living mob when one is available.
- Allows the remainder of the death handler to run for shooterless projectiles
  instead of terminating the event with an exception.

This case was observed with projectiles involving InfernalMobs, splash potions and
BetterRevive death processing. The fix is general and does not add a direct
dependency on any of those plugins.

## Compatibility

- Java 21.
- Paper 1.21.11 is the current validation target.
- CustomItemsLib 1.4.0 is required.
- BagOfGold 4.8.0 is the companion physical-currency release.

## Validation

- All 27 automated regression tests pass.
- Dedicated tests cover projectile deaths both with and without an available shooter.
- Runtime validation on Paper 1.21.11 is pending for the snapshot build.
