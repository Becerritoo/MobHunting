# MobHunting 8.6.0

MobHunting 8.6.0 is the first semantic release of the fork maintained by
[Becerritoo](https://github.com/Becerritoo). Rocologo remains credited as the original author.

## Highlights

- Validated on Paper 1.21.11.
- Separates CMILib action-bar and boss-bar support from the optional CMI integration.
- Prevents an unrelated plugin named Herobrine from triggering the legacy Herobrine API integration.
- Preserves the maintained fork's compatibility and reliability fixes for BetterRevive, MyPet,
  InfernalMobs, Citizens, Towny, bounties and datastore shutdown.
- Reports CMI and CMILib independently in plugin metrics.

## Requirements

- Java 21.
- Paper 1.21.11 is the validated runtime.
- CustomItemsLib 1.1.0-JL.13.
- MyPet 4.0.4 is required only when compiling the optional MyPet integration.

CustomItemsLib and BagOfGold are maintained as related projects, but each project uses its own
semantic version. Their compatibility will be documented with every release.

## Validation

- Maven clean package completed successfully.
- 23 automated tests passed with no failures, errors or skipped tests.
- CMILib integration was exercised without CMI installed.
- Reward payments, deposits, withdrawals and item pickup were verified on Paper 1.21.11.

The plugin version is independent from the Minecraft version. Future Paper compatibility updates
will use patch, minor or major releases according to their effect on MobHunting's API and behavior.
