# MobHunting 8.7.1

MobHunting 8.7.1 replaces the abandoned update source while preserving the
gameplay and integration behavior of 8.7.0.

## Highlights

- Replaces Spiget update checks with the shared Hangar update service from CustomItemsLib.
- Accepts only public, reviewed stable releases compatible with the server's exact Paper version.
- Verifies downloaded JAR size and SHA-256 before staging an update for restart.
- Updates the companion stack to CustomItemsLib 1.4.0 and BagOfGold 4.8.0.

## Compatibility

- Java 21.
- Paper 1.21.11 is the current validation target.
- CustomItemsLib 1.4.0 is required.
- BagOfGold 4.8.0 is the companion physical-currency release.

## Validation

- All 25 automated regression tests pass.
- Complete-stack startup passes on Paper 1.21.11.
- The update command handles the unpublished Hangar project without errors.
- Existing MobHunting gameplay behavior is unchanged from 8.7.0.
