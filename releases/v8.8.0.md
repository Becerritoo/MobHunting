# MobHunting 8.8.0

MobHunting 8.8.0 improves runtime stability and maintenance while preserving the
existing reward and integration model.

## Highlights

- Replaces retained Bukkit entities in grinding history with immutable kill snapshots.
- Bounds and synchronizes grinding history, removes expired entries and avoids empty-history division.
- Uses squared-distance checks for recent farm kills without retaining worlds or entities.
- Rotates `config.yml` backups safely and limits retention through `general.backup_count`.
- Adds `metrics.bstats_enabled` and no longer delays server startup when bStats is disabled.
- Handles translation lookup safely before the selected language has finished loading.
- Includes the MobHunting 8.7.2 fix for projectiles without an available shooter.

## New configuration

- `general.backup_count`: maximum rotating configuration backups, default `10`, bounded from 1 to 100.
- `grinding.history_limit`: maximum recent kill snapshots, default `5000`, bounded from 100 to 100000.
- `metrics.bstats_enabled`: plugin-level anonymous metrics switch, default `true`.

Existing configurations receive these keys through the normal configuration update process.

## Compatibility

- Java 21.
- Paper 1.21.11 is the current validation target.
- CustomItemsLib 1.4.0 is required.
- BagOfGold 4.8.0 is the companion physical-currency release.

## Validation

- Automated tests cover bounded and concurrent grinding history, expiration, backup rotation,
  legacy backup recovery, early translation lookup, metrics selection and projectile attribution.
- Runtime validation passed on Paper 1.21.11 with CustomItemsLib 1.4.0 and BagOfGold 4.8.0.
- Seventy-six recorded kills exercised normal rewards and recovery after speed grinding.
- Speed grinding stopped rewards at the configured ten-kill threshold.
- Area grinding applied progressive multipliers from `0.9` after the warning threshold.
- Repeated restarts rotated ten configuration backups and completed without MobHunting exceptions.
