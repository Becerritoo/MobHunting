# MobHunting 8.6.1

MobHunting 8.6.1 updates the maintained dependency line to CustomItemsLib 1.2.0.

## Changes

- Uses CustomItemsLib 1.2.0.
- Supports CMILib action-bar and boss-bar messages while the optional CMI integration remains disabled.
- Keeps CMI-specific hologram support separate from CMILib visual messages.

## Compatibility

- Java 21.
- Paper 1.21.11 is the validated runtime.
- CustomItemsLib 1.2.0.
- BagOfGold 4.5.6-JL.13 is the validated BagOfGold build at publication time.

## Validation

- Maven clean package completed successfully.
- All 23 automated tests passed with no failures, errors or skipped tests.
- The functional MobHunting classes are unchanged from 8.6.0; this patch aligns the dependency
  and enables the independently configured CMILib integration supplied by CustomItemsLib 1.2.0.
